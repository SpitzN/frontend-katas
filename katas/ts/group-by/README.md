# groupBy

**Track:** TS · **Level:** warm-up

Write `groupBy(items, key)` **and its signature**. The starter's types are `unknown` on purpose: the kata is making the compiler understand the result.

- Groups items by the key the function returns, keeping input order inside each group.
- The key function receives the item with its real type.
- The result's keys are the key function's return type, and a key with no items is absent.

```sh
pnpm kata katas/ts/group-by
```
